JSON to VCF

Небольшой скрипт на Python, который превращает список телефонных номеров из JSON в .vcf файл. Готовый файл можно импортировать в контакты телефона.

Скрипт автоматически приводит российские номера к формату +7 и создаёт отдельный контакт для каждого номера.

Как пользоваться

Для работы нужен Python 3. Никаких дополнительных библиотек устанавливать не нужно.

1. Подготовьте JSON-файл

Создайте файл primorsky_numbers.json и добавьте туда номера телефонов в таком формате:

[
  "89001234567",
  "79009876543",
  "+79991234567",
  "89241234567"
]

Номера должны находиться внутри массива [], каждый в двойных кавычках и через запятую.

2. Запустите скрипт

Положите JSON-файл рядом со скриптом и выполните команду:

python main.py

3. Заберите готовый файл

После запуска в папке появится contacts.vcf. Его можно перекинуть на телефон и импортировать через приложение «Контакты».

Как это работает

Скрипт берёт номера из JSON и создаёт для каждого отдельный контакт.

Например:

89001234567 → +79001234567

79009876543 → +79009876543

+79991234567 → +79991234567

Контакты будут называться по типу Контакт +79001234567, чтобы было понятно, какой номер кому принадлежит.

Пустые значения пропускаются.

Что стоит учитывать

При повторном запуске старый contacts.vcf заменяется новым.

Если в JSON есть одинаковые номера, они попадут в контакты несколько раз.

Скрипт не проверяет, существует ли номер на самом деле.

Лучше использовать российские номера в формате 8XXXXXXXXXX, 7XXXXXXXXXX или +7XXXXXXXXXX.

Пример структуры папки

project/
├── main.py
├── primorsky_numbers.json
└── contacts.vcf

contacts.vcf появится после первого запуска скрипта.

Для чего это нужно

Написал скрипт, чтобы не добавлять большое количество номеров вручную. Достаточно собрать их в один JSON, запустить Python-файл и получить готовый список контактов для импорта на телефон.# convert_to_vcf
